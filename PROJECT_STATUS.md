# StyleFace project status

**Target:** Android native app  
**Business model:** Freemium (UI scaffold only)  
**Photo preview:** Selected selfie with illustrative hair overlay  
**Face-shape detection:** Manual selection in this version  
**Real subscriptions:** Not integrated  
**AI realistic hairstyle transfer:** Not integrated

This is an Android Studio starter source project, not a signed APK. Build it with Android Studio to generate and install the app.
